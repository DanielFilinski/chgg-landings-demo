# ЧГГ-Live — варианты лендинга

Демо-страница с концепциями лендинга для показа заказчику.

- `stol/` — «Стол», кино-версия (экспорт дизайн-макета, React-рантайм в `vendor/`)
- `golosa/` — «Три голоса», короткая версия (экспорт дизайн-макета)
- `golosa-full/` — «Три голоса», полная версия (экспорт дизайн-макета)
- `partiya/` — «Партия до шести»: тексты амбассадоров в игровой подаче (статичный HTML/CSS/JS без зависимостей)
- `nabrosok/` — «Набросок» в стиле логотипа (PDF-макет и его растр)

Локально: `python3 -m http.server` в корне и открыть http://localhost:8000.
